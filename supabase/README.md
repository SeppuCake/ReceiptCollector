# Historical, non-deployed prototype source

This directory preserves the superseded cloud-oriented prototype schema and OCR function for historical review only. It is not part of the approved offline architecture, is not deployed by repository scripts, and must not be enabled by ordinary development or release workflows.

The shipped browser application contains no Supabase client, URL, publishable key, runtime dependency, synchronization path, or deployment command. Any future use would require a new architecture decision and explicit authorization; it is outside the current prototype scope.
